# 伊埃斯 · 无登出之梦

非官方同人网页游戏，原创 CSS 邦布和 CRT 电视格。前三层可玩，零运行依赖。

GitHub Pages 地址：https://abyseker.github.io/tower/ （首次部署需成功启用 Pages）。

部署：Settings → Pages → Source 选择 GitHub Actions，然后在 Actions 中运行 Deploy game to GitHub Pages。后续推送 main 自动部署。

运行：`npm start`；检查：`npm test`。方向键 / WASD 或点击相邻格移动；战斗前确认损血；E 准备水平斩；菜单查看奇遇档案。浏览器本地存档。

## 已实现

- 用户指定的追击彷徨猎手、轻微侵蚀未被察觉、再次进入空洞后昏睡的序章。
- 第一层起始之镇：消失的退出键、攻略组、封弊者、持刀首领与安比布提示。
- 第二层踏鸣原野：牛头首领、比利布锻造铺、强化骗局与食物彩蛋。
- 第三层摇曳迷雾：精灵阵营委托、停战选择、翡翠之钥、守夜回声与无署名邀请。
- 确定伤害、升级、钥匙门、电池、水平斩、丁尼强化、战斗预览、档案、本地存读档。

前三层只埋梦境主人的线索，不直接揭示身份。完整篇章的结局方向依用户设定为「夜魔的游戏」；尚未制作后续楼层和最终结局。现实死亡惩罚并未照搬：致命战斗被阻止。

## 设定与考据边界

剧情是伊埃斯的独立奇遇；邦布化熟人为梦中记忆投影，不引入真实人物被困或新主线事实。夜魔的游戏和动机是用户指定的同人设定，不宣称是官方结论。本文没有将「掌控一切梦境」作为已核实官方能力。
