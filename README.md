# 伊埃斯 · 无登出之梦 / Demo 02

电视格探索 × 魔塔式确定伤害 × 跨楼层分支。非官方、非商业同人作品。

**试玩：[GitHub Pages](https://abyseker.github.io/tower/)** · [部署状态](https://github.com/Abyseker/tower/actions) · [美术图鉴](assets/sprite.html)

## 本版内容

可完整游玩第 1—10 层，另有隐藏层与奖励空间。普通楼层为 40×34 至 52×40 的大型地图，第十层 58×46。每层包含安全区、数量不同的刷怪点、遗迹、特殊事件、首领房。迷雾探索、地图记录、探针标记、黄钥匙与赤色密钥形成路线选择。

- 18 张角色/以骸图像、六种环境图及城区背景，全部为自包含矢量重绘。伊埃斯保留橙色 01 围巾和荧绿眼；刺梨按友好小型哈提重绘。不是官方原画，也不是原作动画资源。
- 镜头跟随、逐格跳跃、碰撞抖动、扫描波、拾取粒子、斩击闪光、传送雪花、对话进场、可选合成音效。
- 确定伤害、水平斩、同步等级、递增价格的攻击/防御强化、练级区休息刷新。重复刷怪奖励降低，等级上限随楼层提升；首领与一次性奖励不刷新。
- 跨层选择影响伙伴、后续援手、城镇规模、每五层/每十层的快速节点与支线奖励。
- 第五层三面镜与第十层末班车广播有独立机制。首领房含两只需扫描才能看见的敌人，配合断路和引导决定完美完成度。
- 第十一至第一百层只有区域、首领档次与远期线索规划，尚未可玩。第一百层结局不在试玩中提前揭露。

## 全键盘

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动、朝向；碰到可交互对象自动停下 |
| F / Enter | 与面前屏幕交互 |
| ↑↓ / Enter / 1—9 | 菜单选择、确认、直接选择 |
| E | 水平斩准备/取消；战斗预演中也可使用 |
| Q | 使用以太电池 |
| I / Tab | 背包 |
| J | 档案 |
| M | 已探索地图 |
| T | 安全区归航 |
| P | 百层区域记录 |
| B | 图鉴 |
| H | 帮助 |
| O | 音效开关，默认静音 |
| Esc | 关闭界面；探索中打开系统菜单 |
| PgUp / PgDn | 翻阅长档案与图鉴 |
| F5 / F9 | 浏览器本地存档 / 读档 |

不需要鼠标，没有限时按键反应要求。旧三层原型的存档与本版不兼容。

## 运行与部署

Node.js 24，无依赖安装、无构建步骤：`npm start`，访问 `http://localhost:3000`。可用 `PORT` 指定端口。GitHub Actions 自动测试并发布 Pages；首次需在 Settings → Pages 将 Source 设置为 GitHub Actions。

## 验证

`npm test` 覆盖十层地图可达性、伤害公式、隐藏层与伙伴分支、无伤装备、第五/十层完美条件、两种城镇、刷怪重置、存档校验，以及没有注入属性、实际逐格行走的十层通关路线。

另以 Chromium 实测纯键盘开场、移动、交互、菜单、背包、档案、地图、图鉴、帮助、存读档；检查页面异常及图像加载。不等同于对全部路线组合的穷举验收。
